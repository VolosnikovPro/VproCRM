# VproCRM v1.1

CRM-система для управления клиентами с интеграцией Avito Messenger.

## Возможности

### Воронка продаж
- Kanban-доска с настраиваемыми этапами (drag-and-drop, цвет, порядок)
- Фильтрация по тексту, этапу, источнику, тегу, задачам
- Пустые колонки скрываются при активном фильтре
- Массовое перемещение и удаление клиентов
- Причины отказа с обязательным выбором

### Карточки клиентов
- Сделка, контакт, телефон, email, организация, адрес, ответственный, бюджет, источник, теги
- Inline-редактирование по двойному клику
- Лента активности (заметки, задачи, файлы, сообщения Avito)

### Задачи
- С датой и временем, группировка (просрочено/сегодня/на неделе/позже)
- Статус выполнения с результатом
- Фильтр задач в воронке

### Дашборд
- Статистика по этапам, источникам, задачам, бюджетам
- Распределение по ответственным, тегам
- График новых клиентов по месяцам

### Объявления Avito
- Таблица с показателями (показы, просмотры, контакты, избранное, расходы)
- Колонки этапов воронки с конверсией
- Тоггл «Статистика воронки» — полное скрытие/показ колонок
- Прилипание шапки и строки итогов при скролле
- Счётчик активных/всего объявлений
- Дата обновления под кнопкой синхронизации
- Группировка объявлений по папкам
- Восстановление снятых объявлений

### Интеграция с Avito
- OAuth2 авторизация (client_credentials)
- Синхронизация чатов и сообщений (SDK V2/V3) каждые 60 секунд
- Отправка ответов, статус прочтения
- Автоматическое создание клиентов из чатов
- Ежедневная статистика по API Avito V2 (1 запрос/мин)

### Прочее
- Поиск и фильтры
- Экспорт/импорт CSV
- Тёмная тема с переключателем
- Уведомления (колокольчик, лента, звук для Avito, отметка о прочтении)
- Резервное копирование и восстановление БД
- Объединение дубликатов
- Hotkeys: Ctrl+N, Ctrl+F, Escape, Ctrl+S
- Управление этапами в модальном окне

## Стек

- Python 3.14, FastAPI, SQLAlchemy, SQLite
- HTML/CSS/JS (vanilla, без фреймворков)
- PyInstaller (сборка .exe)
- Playwright (тестирование)

## Запуск

### Из исходников

```bash
pip install -r requirements.txt
python main.py
```

Откроется в браузере по адресу http://127.0.0.1:8000

### Из .exe

Запустить `dist/VproCRM.exe` — сервер стартует автоматически.

## Сборка .exe

```bash
python -m PyInstaller VproCRM.spec --noconfirm
```

## Тестирование

```bash
pip install playwright
python test_webapp.py
```

## Структура

```
├── server.py         # API сервер (FastAPI)
├── main.py           # Точка входа (webview + server)
├── database.py       # Подключение к БД, миграции
├── models.py         # SQLAlchemy модели
├── schemas.py        # Pydantic схемы
├── test_webapp.py    # Playwright smoke-тесты
├── static/           # Фронтенд
│   ├── index.html
│   ├── app.js
│   └── style.css
├── avito_api/        # Avito Messenger SDK (vendored)
├── docs/superpowers/ # Документация и планы
├── VproCRM.spec      # Конфиг PyInstaller
└── requirements.txt  # Зависимости
```

## Важно

- База данных `crm.db` создаётся автоматически рядом с .exe (или в папке проекта)
- При перезапуске данные сохраняются
- Для Avito необходимы client_id и client_secret (настройка в разделе Интеграции)
